Wyze Tunnel setup

Let's connect your Wyze cameras

This takes about two minutes. You'll need your Wyze email and password, and you'll make a free "API key" on Wyze's website so Wyze Tunnel can sign in for you.

Make your Wyze API key

  1. Open the Wyze developer console (it opens in a new tab).
  2. Sign in with the same Wyze account you use in the Wyze app.
  3. Click Create an API key. Any name works, like "Wyze Tunnel".
  4. Copy the Key ID and the API Key it shows you, and paste them below.
